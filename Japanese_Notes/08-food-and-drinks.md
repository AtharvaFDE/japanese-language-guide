## 🔗 2. Useful Connector & Request

### と (To) = AND

The Japanese word と connects two nouns.

**Formula:**

`A + と + B = A and B`

Examples:

- おちゃ と みず = Green tea and water.
- すし と ごはん = Sushi and rice.
- みず と すし = Water and sushi.
- すし と おちゃ = Sushi and green tea.

### ください (Kudasai) = PLEASE

Used to politely ask for something.

Examples:

- みず、ください。 = Water, please.
- すし、ください。 = Sushi, please.
- おちゃ、ください。 = Green tea, please.

### を (O) = OBJECT PARTICLE

The particle を marks the object of an action.

Example:

- おちゃ を のみます。 = I drink green tea.

### が (Ga) = SUBJECT / LIKING PARTICLE

The particle が is commonly used with すきです (suki desu) to express liking something.

Example:

- おちゃ が すきです。 = I like green tea.
