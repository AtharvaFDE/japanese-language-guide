## 🔗 3. Useful Connector & Request

### と (To) = And

Connects two nouns.

```text
A + と + B = A and B
```

Example:

```text
みず と すし
Mizu to sushi
Water and sushi
```

### ください (Kudasai) = Please

Used to make polite requests.

<details>
<summary>💡 Learn how to use ください</summary>

Add ください at the end of a request.

Example:

```text
すし、ください。
Sushi, kudasai.
Sushi, please!
```

</details>
